Procedural CTF-Generator for LLM-Agents

August 2026 – September 2026

Framework for generating random cryptographic capture-the-flag challenges based around a reversible nonce-generation mechanism. Produced challenges are meant to stress test LLM's cryptographic capabilities. The LLM's ability to solve the challenge instance is tested by expressing the recursive nonce generator as an arbitrary collection of permutated and nested quadratic, linear and constant terms. Implementation includes verification of a generated challenge for guaranteed solvability. Extension to similar and more involved cryptographic vulnerabilities possible.

  • quadratic nonce generation
  • exploitation via linear substitution
  • verification of challenge solvability
  • difficulty tuning for nonce expression depth
  • LLM capability testing with domain-specific hinting
  • data contamination robustness

Zero-Knowledge IVC-based Proof System for AI-Agents

April 2026 – June 2026

Build and deployment of a zero-knowledge prooving pipeline tailored to LLM-agents in productive environments. The implementation is a Proof-of-Concept showcasing how proof circuits can be generated and accumulated via a folding mechanism, thus enabling incremental verification (IVC). Use of this mechanism is in general intended for systems continuously producing outputs which need to be verified for correctness and compliance against an established policy. In particular, the PoC can be applied to agentic environments in which the continuously increasing trace of the agent's activity (e.g. tool calls) can be efficiently translated into a proof circuit via IVC. Practical use-cases may include automated trading agents, banking services integrating agents and automated processes in healthcare (e.g. management of medical data).

  • real-time proof circuit generation
  • evaluation of R1CS circuits
  • incremental verification of agent traces
  • policy enforcement via circuit expressions
NOVA Folding IVC LLM-Agents LangChain Rust
